### Project Description

RoastCam is a fun, useless-but-technically-impressive AI web application that uses a webcam to detect facial emotions, raised fingers, and mouth position in real time. It combines these detections to generate humorous roasts, reads them aloud, and turns the experience into a gamified AI interaction.

### The Problem (that doesn't exist)

People apparently need AI to tell them what their face, fingers, and mouth are doing—even though they can already see or feel them. RoastCam solves this extremely important problem that nobody actually has.

### The Solution (that nobody asked for)

RoastCam uses real-time computer vision to detect facial emotions, count raised fingers, and analyse mouth position. It combines these results to generate sarcastic roasts and reads them aloud using text-to-speech, while missions, XP, combos, and a pixel-art octopus make the experience even more unnecessarily entertaining.
